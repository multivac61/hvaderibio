# Agent notes

This app uses Svelte 5 (runes) and SvelteKit 2. Training data skews towards
Svelte 4 syntax, so check the official LLM docs before writing or reviewing
`.svelte`, `.svelte.ts`, or route files:

- [Svelte](https://svelte.dev/docs/svelte/llms-small.txt): runes, components,
  template syntax.
- [SvelteKit](https://svelte.dev/docs/kit/llms-small.txt): routing, load
  functions, hooks, adapters.
- [Full docs](https://svelte.dev/llms-full.txt): every example and edge case,
  when the compressed sets leave a question open.

The [index](https://svelte.dev/docs/llms) lists the remaining sets.
